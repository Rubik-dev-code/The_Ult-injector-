## 🚀 How to Install and Use

### Step 1: Create the Bookmark
1. Open your web browser and make sure your **Bookmark Bar** is visible (`Ctrl + Shift + B` or `Cmd + Shift + B`).
2. Right-click an empty space on the bar and select **Add Page** or **Bookmark this tab**.
3. Name the bookmark whatever you want (e.g., `🔥 R+ Injector`).

### Step 2: Add the Source Code
1. Copy the complete, unified JavaScript bookmarklet code from the file in this repository.
2. Edit your newly created bookmark and paste that code directly into the **URL** or **Location** field box.
3. Click **Save**.

### Step 3: Inject the Dashboard
1. Navigate to your favorite game page (like `://blooket.com`).
2. Once the website is fully loaded, click your `🔥 R+ Injector` bookmark.
3. Watch the custom dashboard pop open instantly, choose your module, and enjoy!
